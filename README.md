# DSA-VISUALIZER
🚀 DSA Visualizer

An interactive algorithm visualization platform that dynamically simulates data structures and algorithms with real-time execution tracing and animated rendering.

🔥 Features

📊 Sorting Algorithms (Bubble, Merge, Quick)

📦 Stack & Queue Simulation

🔍 Binary Search Visualization

⚙️ Dynamic Python Execution Engine

🧠 Step-by-Step Execution Trace

🎮 Interactive Controls (Play, Pause, Step, Speed Control)

🎨 Modern Responsive Dashboard UI

🏗 Architecture Overview

The system is built using a modular node-based workflow engine:

Algorithm Selection Layer

Accepts user input (algorithm type + data)

Simulation Engine

Dynamically generates Python code

Executes algorithm inside sandbox

Produces structured execution trace

Trace Processor

Converts execution steps into renderable state objects

Visualization Renderer

HTML + CSS layout

JavaScript animation engine

State-based UI updates

🛠 Tech Stack

React (UI Layer)

Tailwind CSS (Modern Design System)

Python (Algorithm Simulation)

Execution Trace Engine

Dynamic Rendering Pipeline

🧩 How It Works

User selects algorithm

System generates execution logic

Python simulation runs

Execution trace captured

Frontend animates each step
